HARDWARE + SOFTWARE + GARDEN / FIELD NOTES 03

Smart Lawn

In development Working software prototype

A small lawn. A closer look beneath the surface.

What started as an idea for watering my 50 m² lawn is becoming My Garden — a mobile soil-monitoring app, with two wired probes and an ESP32 controller planned for the garden. The software can already be explored; the hardware connection is the next step.

See the soil. Follow the changes.

02 / THE ENGINEERING BEHIND THE SCREEN

What if a reading never arrives?

A reassuring number is only useful if it can be trusted. The prototype checks freshness and time quality, preserves gaps in the history, and withholds watering suggestions when readings are unreliable. A dry trend must remain valid for an uninterrupted 30-minute window before the current logic suggests watering.

DEVELOPMENT EXAMPLE / A LOST ACKNOWLEDGEMENT

Send again. Keep one reading.

A measurement can reach the database even when its acknowledgement never reaches the device. The local queue model and ingestion code are tested together: resend that measurement, keep a single database record, then remove only the readings that have been acknowledged.

This verifies the software model locally. ESP32 firmware and real flash power-loss testing still come next.

The backend code is prepared for Supabase authentication, owner-scoped database access and a separate device upload key. The public demo runs on simulated data, with cloud configuration disabled.

Supabase / PostgreSQL · Access rules · Idempotent ingestion · Local automated checks

Cloud deployment has not been validated. Watering advice uses preliminary user-defined thresholds, not validated agronomic guidance.

01 / HARDWARE Ordered

ESP32-S3 controller

A board sold as ESP32-S3-RS485-CAN will bridge the wired probes and Wi-Fi. The exact board variant, pin mapping and power requirements still need to be verified on arrival.

02 / HARDWARE Ordered

Two wired soil probes

One moisture / temperature probe and a second with an additional pH channel. RS485 / Modbus RTU is the intended connection; register maps, scaling and calibration come next. pH is experimental.

03 / HARDWARE In planning

Power & outdoor enclosure

A 12 V supply, protected connections and a serviceable enclosure are being considered together. Power compatibility, cable entries and the final cable route need checking before installation.

04 / HARDWARE Future stage

Irrigation, later

The first goal is dependable monitoring. A valve, driver and watering rules can follow once real readings and failure behaviour have been checked. No irrigation is connected today.

04 / THE REAL GARDEN

A practical question, close to home.

I still water the lawn manually. Sun, shade and soil conditions can make nearby areas behave differently. I want to compare how quickly they dry, how the soil temperature changes, and how long water takes to reach a probe.

This is the part I enjoy: connecting the interface to something physical, making the measurements understandable, and checking the whole path from a sensor in the ground to a decision on the screen.

05 / CURRENT STATE & NEXT STEPS

Measure first. Automate later.

  1. Working locally

    Mobile interface, simulated scenarios, history, settings and CSV export. Backend and queue behaviour have local automated checks.

  2. Hardware integration next

    Verify the delivered board and probe documentation, implement the firmware, then test communication, calibration and recovery on the bench.

  3. Connect and observe

    Validate the hosted backend, collect real readings and compare both locations through ordinary watering and weather changes.

  4. Consider irrigation

    Only after reliable monitoring: test a valve, shut-off behaviour and watering limits. Weather, notifications and automatic control remain future work.
