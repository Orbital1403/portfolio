01 / Portfolio

Portfolio

Osobna web-stranica · U razvoju

Ova web-stranica također je jedan od mojih projekata. Postojeću Astro temu prilagođavam u portfolio koji povezuje moje iskustvo, praktičan rad i aktualne interese.

Pozadina tehničkog papira i prepoznatljiva tipografija zadržane su iz izvorne teme. Dorađujem strukturu, tekstove, predstavljanje projekata, prilagodljive rasporede i male interakcije.

Cilj je jasan i iskren prikaz onoga što sam radio i što učim, uz fotografije i bilješke koje rad čine opipljivim.

Temelj: Astro · HTML/CSS · JavaScript · Markdown · Tema Typography

Obrazovanje i daljnje učenje

Završio sam obrazovanje za Java developera i trenutačno pohađam program AI & Machine Learning na ITAcademyju. Znanje Pythona, obrade podataka i AI/ML-a razvijam uz praktičan rad na projektima MILA* i grgaGrow. Detalji o trenutačnom obrazovanju i potvrdama o završenim tečajevima nalaze se na stranici Vještine .
